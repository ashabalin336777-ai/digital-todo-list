# Список задач

Небольшое веб-приложение для учёта дел. Задачи добавляются, отмечаются выполненными и удаляются в браузере. Список сохраняется локально и восстанавливается после перезагрузки страницы.

Стек: HTML, CSS и JavaScript без фреймворков и сборщиков. В контейнере статику отдаёт nginx.

## Функции

- Добавление задачи кнопкой «Добавить» и клавишей Enter. Пустая строка и строка из пробелов не попадают в список.
- Отметка «выполнено» чекбоксом. Выполненная задача зачёркивается и становится бледнее. Повторный клик снимает отметку.
- Удаление отдельной кнопкой у каждой задачи.
- Сохранение в `localStorage`. После обновления страницы список на месте. Повреждённые данные не ломают страницу: приложение начинает с пустого списка.
- Счётчик «осталось N из M».
- Надпись «Задач пока нет», когда список пуст.

У задачи есть поля `id`, `text`, `done` и `createdAt`. Текст выводится через `textContent`, без `innerHTML`.

## Запуск локально

Откройте `index.html` в браузере. Для этого достаточно двойного щелчка по файлу: страница не обращается к серверу, данные хранятся в `localStorage`.

Другой вариант — поднять простой статический сервер из папки проекта:

```bash
python -m http.server 8080
```

После этого сайт доступен на http://localhost:8080.

## Запуск через Docker

В корне репозитория:

```bash
docker build -t todo .
docker run -p 8080:80 todo
```

Образ собран на `nginx:alpine`. Файлы `index.html`, `style.css` и `app.js` копируются в `/usr/share/nginx/html`, контейнер слушает порт 80. Сайт открывается на http://localhost:8080.

Остановить контейнер: `Ctrl+C` в том же терминале.

## Деплой на Timeweb Apps

Приложение рассчитано на [Timeweb Cloud App Platform](https://timeweb.cloud/docs/apps/deploying-with-dockerfile): сервис собирает образ из `Dockerfile` в корне репозитория и сам направляет трафик с портов 80 и 443 на порт из `EXPOSE`.

1. Зайдите в [панель Timeweb Cloud](https://timeweb.cloud/) и откройте раздел App Platform.
2. Нажмите «Создать» и подключите GitHub-аккаунт, если он ещё не подключён.
3. Выберите репозиторий `digital-todo-list` и ветку `main`.
4. Оставьте сборку по Dockerfile. Файл лежит в корне, в нём указано `EXPOSE 80` — этот порт слушает nginx.
5. Нажмите «Запустить деплой» и дождитесь статуса готовности во вкладке «Деплой».
6. Адрес и технический домен появятся на вкладке «Дашборд».

Документация: [деплой из Dockerfile](https://timeweb.cloud/docs/apps/deploying-with-dockerfile).
