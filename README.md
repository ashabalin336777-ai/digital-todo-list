# Список задач

Версия 2.0. Тестовое задание для компании Digital.

Личный список дел в браузере. Задачу можно добавить, разметить по группе и времени, отметить выполненной, отредактировать, отправить в архив или удалить. Данные остаются на этом устройстве: бэкенда нет, всё хранится в `localStorage`.

Стек: React 18 и Vite, JavaScript без TypeScript. Стили — обычный CSS, без UI-библиотек и без библиотек календаря.

Задачи первой версии читаются из того же ключа `todo-tasks`. Недостающим полям подставляются значения по умолчанию, повреждённый JSON не ломает страницу.

## Функции

- Добавление кнопкой «Добавить» и клавишей Enter. Пустая строка и строка из пробелов не добавляются.
- Группа: Личные, Работа, Учёба или Дом. По умолчанию — Личные.
- Необязательные «Начало» и «Окончание». Если окончание раньше начала, задача не сохраняется, под полем видна подсказка.
- Отметка «выполнено». Выполненная задача зачёркивается и становится бледнее. Повторный клик снимает отметку.
- Карточка показывает цветную метку группы и время в формате «18 нояб., 10:00 — 12:30». Просроченная невыполненная задача подсвечена коралловым и помечена «Просрочено».
- Редактирование в окне: текст, группа и даты. Удаление. Кнопка «В архив».
- Вкладки «Все», «Личные», «Работа», «Учёба», «Дом» и «Архив» со счётчиком. «Все» — только неархивные. Выбранная вкладка запоминается.
- Вид «Список» или «Календарь». Месяц с понедельника, переход по месяцам, кнопка «Сегодня», сегодняшний день выделен. В ячейке — число задач с началом в этот день. Клик по дню показывает задачи дня и подставляет дату в поле «Начало». Календарь учитывает выбранную группу.
- В архиве — «Восстановить» и «Удалить навсегда» с подтверждением. «Архивировать выполненные» убирает все выполненные сразу.
- Сортировка: невыполненные сверху по времени начала (без даты — в конце своей части), выполненные внизу.
- Счётчик «Осталось N из M» и надпись «Задач пока нет».
- Текст задачи выводится как текст React, без `dangerouslySetInnerHTML`.

## Запуск

Нужен Node.js 18 или новее.

```bash
npm install
npm run dev
```

Сайт разработки откроется по адресу, который покажет Vite. Обычно это http://localhost:5173.

## Сборка

```bash
npm run build
npm run preview
```

`npm run build` собирает статику в `dist/`. `npm run preview` показывает эту сборку локально.

## Деплой на Timeweb Apps

Приложение рассчитано на Timeweb Cloud Apps с типом «Фронтенд» и фреймворком React.

1. Зайдите в панель Timeweb Cloud и откройте Apps.
2. Создайте приложение и подключите репозиторий `digital-todo-list`, ветка `main`.
3. Фреймворк: React.
4. Команда сборки: `npm run build`.
5. Директория публикации: `dist`.
6. Запустите деплой и дождитесь готового адреса на дашборде.

В `vite.config.js` указано `base: '/'`. В `package.json` задано `"engines": { "node": ">=18" }`.

## Использованные AI-инструменты

Интерфейс и логика собраны в редакторе Cursor. Техническое задание подготовлено с помощью AI-ассистента. Сторонние UI-библиотеки и библиотеки календаря не подключались.
